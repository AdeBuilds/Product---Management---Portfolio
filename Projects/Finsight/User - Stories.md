# FinSight — User Stories

## Epic 1: Financial Assessment

### User Story 1
As an SME owner, I want to enter my business financial information so that I can assess my business's financial health.

### User Story 2
As an SME owner, I want clear instructions when entering my financial information so that I can provide accurate data.

### User Story 3
As an SME owner, I want to update my financial information so that my assessment remains accurate.

## Epic 2: Financial Health Score

### User Story 4
As an SME owner, I want to receive a financial health score so that I can quickly understand the financial position of my business.

### User Story 5
As an SME owner, I want to understand what my financial health score means so that I can take appropriate action.

## Epic 3: Financial Insights

### User Story 6
As an SME owner, I want to receive simple financial insights so that I can understand the strengths and weaknesses of my business.

### User Story 7
As an SME owner, I want actionable recommendations so that I know what steps I can take to improve my financial health.

## Epic 4: Risk Identification

### User Story 8
As an SME owner, I want the product to highlight potential financial risks so that I can address them early.

### User Story 9
As an SME owner, I want to understand why a financial risk has been identified so that I can make informed decisions.

## Epic 5: Dashboard

### User Story 10
As an SME owner, I want to see my key financial indicators in one place so that I can easily monitor my business performance.

### User Story 11
As an SME owner, I want to track changes in my financial health over time so that I can see whether my business is improving.

## Acceptance Criteria

Each user story should meet the following criteria:

- The user can complete the intended action.
- The information presented is clear and understandable.
- The system provides appropriate feedback.
- The feature works as intended without errors.
