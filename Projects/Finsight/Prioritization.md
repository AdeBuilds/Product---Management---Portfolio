# FinSight — Feature Prioritization

## Prioritization Framework

The MoSCoW framework was used to prioritize FinSight features based on their importance to the Minimum Viable Product (MVP).

MoSCoW stands for:

- Must Have
- Should Have
- Could Have
- Won't Have for now

## Must Have

These features are essential for the MVP.

- User registration
- Financial information input
- Financial health assessment
- Financial health score
- Basic financial dashboard
- Basic financial recommendations
- Risk indicators

## Should Have

These features provide significant value but are not essential for the first release.

- Financial health history
- Detailed financial insights
- Customizable financial reports
- Educational financial tips

## Could Have

These features could improve the product experience but can be developed later.

- Financial forecasting
- Budgeting tools
- Business performance comparisons
- Personalized financial improvement plans

## Won't Have for Now

These features are intentionally excluded from the MVP to keep the initial product focused.

- Direct connection to bank accounts
- Automated accounting integration
- Advanced AI financial forecasting
- Financial advisor marketplace

## Prioritization Rationale

The MVP focuses on helping SME owners answer three key questions:

1. How financially healthy is my business?
2. What financial risks should I be aware of?
3. What can I do to improve my financial position?

Features that directly support these questions receive the highest priority.

## MVP Focus

The initial release will focus on:

- Collecting relevant financial information.
- Assessing financial health.
- Presenting a simple financial health score.
- Identifying potential risks.
- Providing actionable recommendations.

This approach allows the product team to validate the core value proposition before investing in more advanced features.
